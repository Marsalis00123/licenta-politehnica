Proiect de diploma · Inginerie Medicala · 2018

Clasificarea Hemangioamelor Infantile Utilizand Retele Neuronale

O lucrare despre folosirea retelelor neuronale convolutionale pentru analiza si clasificarea imaginilor medicale asociate hemangioamelor infantile.

Lucrarea PDF Prezentarea Codul pe GitHub

Pe scurt

Proiectul combina preprocesarea imaginilor, generarea de sub-imagini si antrenarea unor arhitecturi CNN in MATLAB pentru clasificarea leziunilor.

CNN Arhitecturi pentru clasificare in doua si trei clase.
MATLAB Implementare si evaluare experimentala folosind toolchain-ul MATLAB.
CAD Context de diagnoza asistata de calculator pentru imagini medicale.
