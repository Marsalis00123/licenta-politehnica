# MATLAB

Acest folder conține o selecție din scripturile MATLAB folosite pentru:

- preprocesarea imaginilor și generarea crop-urilor;
- definirea arhitecturilor CNN pentru două și trei clase;
- evaluarea acurateții;
- testarea rețelelor pe imagini noi.

Scripturile au fost păstrate ca material de portofoliu și pot necesita adaptări pentru a rula pe un dataset nou sau pe versiuni recente de MATLAB.
