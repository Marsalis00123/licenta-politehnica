# MATLAB

Acest folder contine o selectie din scripturile MATLAB folosite pentru:

- preprocesarea imaginilor si generarea crop-urilor;
- definirea arhitecturilor CNN pentru doua si trei clase;
- evaluarea acuratetii;
- testarea retelelor pe imagini noi.

Scripturile au fost pastrate ca material de portofoliu si pot necesita adaptari pentru a rula pe un dataset nou sau pe versiuni recente de MATLAB.
