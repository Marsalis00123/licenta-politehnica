Proiect de diplomă · Inginerie Medicală · 2018

Clasificarea Hemangioamelor Infantile Utilizând Rețele Neuronale

O lucrare despre folosirea rețelelor neuronale convoluționale pentru analiza și clasificarea imaginilor medicale asociate hemangioamelor infantile.

Lucrarea PDF Prezentarea Codul pe GitHub

Pe scurt

Proiectul combină preprocesarea imaginilor, generarea de sub-imagini și antrenarea unor arhitecturi CNN în MATLAB pentru clasificarea leziunilor.

CNN Arhitecturi pentru clasificare în două și trei clase.
MATLAB Implementare și evaluare experimentală folosind toolchain-ul MATLAB.
CAD Context de diagnoză asistată de calculator pentru imagini medicale.
